# Makao.UZ
## Dependencies
- Node
- NPM
## How to launch
1. Clone this repository localy,
1. ``` npm install ``` 
1. In one terminal,
``` npm run server ```
1. In the second terminal,
``` npm run dev ```
1. Connect to localhost:3001,
## Playing on LAN
1. In serverConfig.json change ip to your local ip adress (for example 192.168.0.12),
1. In your firewall open ports 3000 and 3001,
1. Lauch frontend and backend,
1. Users join through a browser to your ip at port 3001 (for example 192.168.0.12:3001),
